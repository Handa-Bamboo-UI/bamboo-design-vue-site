# 😀Icon Icon
Icon component for displaying icons.
Based on [Font Awesome](https://fontawesome.com/) icon library.
## 🌈 Basic Properties
| Property Name | Type | Default Value | Description |
| --- | --- | --- | --- |
| type | String | 'fa-check' | Icon type, refer to [Font Awesome icon library](https://fontawesome.com/icons?d=gallery&s=solid&m=free) |
| size | String | '1x' | Icon size, refer to [Font Awesome icon library](https://fontawesome.com/icons?d=gallery&s=solid&m=free) |
